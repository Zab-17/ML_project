# Archive — Egyptian developer tables (Phase 1, not part of the current project)

These files belong to the FIRST version of this project: predicting residential
asking prices in Greater Cairo. The professor rejected that version because the
dataset was too small, so the project moved to the Zillow properties file for
Los Angeles, Orange and Ventura counties.

**Nothing here is used by the current pipeline.** It is kept only because the work
is real and may matter again if the project ever returns to the Egyptian market.

- `developers.csv` — 225 Egyptian real-estate developers, with identity, scale and track record
- `projects.csv` — 1,090 of their projects, 696 of them in Greater Cairo
- `compound_lookup.csv` — Egyptian compound names as they appear in listings, linked to developers
- `sources.csv` — the 549 sources every value above was taken from
- `build_*.py`, `stage1/`, `stage2/` — the scripts and raw agent output that produced the tables
